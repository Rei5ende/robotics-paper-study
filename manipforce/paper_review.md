# ManipForce

**논문:** ManipForce — Force-Guided Policy Learning with Frequency-Aware Representation for Contact-Rich Manipulation (ICRA 2026) / arXiv:2509.19047 / GIST AILab

## 한 줄 요약

로봇이 기어 끼우기·배터리 삽입처럼 힘 조절이 중요한 작업을 잘하도록, 카메라 영상에 **힘 센서 감각을 원래의 빠른 속도 그대로** 합쳐 넣는 방법.

## 무슨 문제를 푸나

로봇에게 사람 시연을 보고 배우게 하는 imitation learning은 보통 **카메라 영상만** 쓴다. 그런데 부품이 딱 맞물려야 하는 정밀 조립(contact-rich) 작업은 "얼마나 세게, 어느 방향으로 미느냐"가 성패를 가르는데, 이건 카메라에 잘 안 보인다. 특히 접촉 순간엔 부품이 손이나 그리퍼에 가려져 시각이 거의 무력해진다.

"그럼 힘 센서를 붙이면 되지"가 당연한 답이지만, 여기서 진짜 문제가 생긴다. **카메라는 느리고(수십 Hz), 힘은 훨씬 빠르게 변한다.** 두 신호를 맞추겠다고 힘 데이터를 카메라 속도로 낮춰버리면, 정작 중요한 순간적인 힘 변화가 통째로 사라진다.

## 핵심 아이디어

- **데이터 수집(ManipForce 장치):** 로봇을 원격조작하지 않고, 사람이 **손에 드는 장치**로 직접 작업하면서 RGB 영상과 힘/토크(F/T) 값을 함께 기록한다. 사람이 자연스럽게 하니 진짜 힘 쓰는 패턴이 담기고 수집도 싸고 빠르다.
- **모델(FMT, Frequency-Aware Multimodal Transformer):**
  - 영상과 힘을 **같은 속도로 맞추지 않고 각자의 속도 그대로** 사용한다.
  - 각 데이터 조각(token)에 "이게 영상인지 힘인지" + "어느 속도/시점의 신호인지"를 알려주는 꼬리표(embedding)를 붙인다.
  - **양방향 cross-attention**으로 영상이 힘을 참고하고, 힘도 영상을 참고하게 한다. 한쪽이 다른 쪽에 종속되는 구조가 아니다.
  - 이렇게 합쳐진 정보를 **diffusion policy** 위에 얹어 최종 로봇 동작을 만든다.

비유하면, 눈(느린 카메라)과 손끝(빠른 힘 센서)을 억지로 같은 속도로 맞추지 않고, 각자 잘하는 속도로 일하게 하면서 서로 대화시키는 구조.

## 결과

실제 작업 6개, 각 20회 시도 기준.

| 작업 | 영상만 | FMT(영상+힘) |
|---|---|---|
| Gear Assembly | 0.35 | 0.95 |
| LAN Plug Insertion | 0.40 | 0.85 |
| Box Flipping | 0.05 | 0.90 |
| Open Lid | 0.20 | 1.00 |
| Battery Disassembly | 0.20 | 0.65 |
| Battery Insertion | 0.10 | 0.60 |

- 평균 성공률 **약 22% → 약 83%**.
- 비교 대상(영상만)도 DINOv2 인코더 + 같은 policy를 쓴 제대로 된 baseline이라, 향상은 "더 좋은 비전 모델" 덕이 아니라 **힘 정보를 넣은 덕**이다.
- **Ablation이 핵심 주장을 뒷받침:** 힘 데이터를 저주파(약 30Hz)로 낮추면 성능이 떨어지고, 꼬리표(embedding)나 cross-attention을 빼도 떨어진다. 즉 "힘이 도움 된다"를 넘어 **"빠른 힘 정보 + 제대로 된 융합"이 핵심**이라는 뜻.

## 나의 관심과의 연결

- PyTorch로 구현해 본 **Diffusion Policy에 멀티모달 입력단을 붙인 구조**라, 코드에 힘 스트림 + cross-attention
- CS231n에서 cross-attention을 ViT/CLIP 같은 **시각-언어** 융합으로 배웠는데, 여기선 같은 기법을 **시각-힘** 융합에 쓴다. 
- force-aware 정책은 ForceVLA·TA-VLA처럼 **VLA와 수렴 중**이라, 작은 힘 신호가 어떻게 융합되는지 먼저 이해해 두면 대형 VLA로 넘어갈 때 발판이 된다.
- PolyFit은 힘으로 **자세 오차를 추정·교정**하는 supervised 방식, ManipForce는 힘을 **정책 입력으로 직접 융합**하는 imitation learning 방식. 같은 "힘·접촉 기반 매니퓰레이션" 흐름의 두 갈래로 묶어 보면 좋다.

## 용어 메모

- **F/T(Force/Torque) 센서:** 접촉할 때 걸리는 힘 3축(Fx, Fy, Fz)과 토크 3축(Tx, Ty, Tz)을 재는 센서. 로봇에게 붙여주는 "손끝 감각".
- **contact-rich manipulation:** 제어된 물리적 접촉이 성공에 필수인 작업(끼우기, 조립, 뒤집기). 허공에서 움직이는 작업과 대비된다.
- **cross-attention:** 한쪽 신호가 다른 쪽 신호에서 필요한 정보를 찾아보게 하는 구조. "양방향"이면 영상→힘, 힘→영상 둘 다 수행.
- **frequency-aware embedding:** 각 데이터 조각에 센서 종류와 샘플링 속도/시점을 알려주는 추가 정보. 빠른 신호와 느린 신호를 같은 속도로 억지로 맞추지 않고 함께 다루게 해준다.
- **diffusion policy:** 노이즈에서 시작해 조금씩 다듬어(denoising) 로봇 동작을 생성하는 정책. 여러 갈래의 동작 분포를 잘 다루는 게 장점.
